## Data and models

Licences were read at the source on 2026-11-15. The data is downloaded by
`python -m app.ml.train` into `data/`, which is git-ignored: no dataset is
redistributed in this repository. Only the trained model is.

| Data | Used for | Licence | Source |
|---|---|---|---|
| Amazon Polarity | Training, in-domain test | Apache-2.0 | https://huggingface.co/datasets/fancyzhx/amazon_polarity |
| Sentiment Labelled Sentences | Cross-domain test | CC BY 4.0 | https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences |

Citations:

- Zhang, X., Zhao, J., LeCun, Y. (2015). Character-level Convolutional Networks
  for Text Classification. NeurIPS 28. (Amazon Polarity; built from the Amazon
  review data of McAuley and Leskovec, 2013.)
- Kotzias, D. (2015). Sentiment Labelled Sentences. UCI Machine Learning
  Repository. https://doi.org/10.24432/C57604. Introduced in Kotzias, Denil,
  de Freitas, Smyth (2015), From Group to Individual Labels Using Deep Features, KDD.

Considered and **not used** because the licence is unclear at the source:
IMDB Large Movie Review (`stanfordnlp/imdb`, licence "other") and SST-2
(`stanfordnlp/sst2`, licence "unknown").

`models/sentiment-v1.joblib` is trained by this project on Amazon Polarity.
